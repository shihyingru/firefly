# 13|隱私與法遵評估

> 螢火 Firefly|v0.1|2026-07-20|AGPL-3.0
> 本文件為工程用風險地圖,非法律意見。上線前與掛載體前各安排一次專業法務諮詢(預算列入文件 11)。

## 個資層(台灣個資法/GDPR)

| 設計事實 | 法遵效果 |
|---|---|
| 不存 IP(防濫用 24h 滾動刪)、不存國籍、不存真實身分、平台識別碼僅單向雜湊 | 個資持有面積趨近零;被索取/外洩時無個人層級資料可交付 |
| 識讀日記純裝置端、免登入 | 敏感推斷資料(閱讀傾向)不落地伺服器 |
| 禁止被動閱讀追蹤(含匿名) | 迴避「匿名行為資料可再識別」的整類風險 |
| 具名貢獻者僅自選暱稱＋登入憑證 | 蒐集目的明確、最小化;提供刪除自助功能 |
| 開放資料 k-匿名化 | 研究釋出不構成個資揭露 |

待辦:隱私權政策(雙語)、GDPR 代表義務評估(若歐盟使用者達門檻)、資料保護影響評估(DPIA)輕量版。

## 內容層(誹謗/名譽風險)

- 核心防線即產品設計:卡片僅陳述可驗證事實(時間、數量、連結),不作「操弄/假帳號/側翼」等定性——事實陳述有真實性抗辯,定性評價才是誹謗高風險區
- 帳號代號呈現:卡片顯示平台公開代號屬公開資訊轉述;仍設申訴遮蔽管道(文件 09)
- AI 輸出護欄(文件 04 白名單＋後驗證)同時是法律護欄:系統性排除意圖歸因
- 殘餘風險:聚類錯誤導致無辜帳號被關聯 → 複審佇列優先級最高＋錯誤更正紀錄公開

## 平台條款層

| 平台 | 依賴 | 風險與對策 |
|---|---|---|
| Threads API | mention/回覆/發文 | 額度與政策生殺在 Meta;feature flag 一鍵下線;過審材料完備;絕不爬取非 API 資料 |
| LINE Messaging API | Bot 全功能 | 條款穩定;回覆模式合規;不儲存原始 userId |
| 快照擷取 | 公開網頁 | 僅公開內容、遵守 robots 與速率;Wayback 為主要存證,自建快照為輔 |

## 政府索資應對

- 可交付面積最小化為第一防線(見個資層)
- 透明報告:每季公開收到的索資要求次數與類型
- Warrant canary:評估後採用——儀表板常設「本季未收到附保密令之索資要求」聲明,消失即為訊號;法律有效性依轄區而異,列入法務諮詢清單
- 跨國部署方(AGPL 分岔)自負當地法遵;README 明示

## 營運者個人保護

- 維護者具名經營(透明要求)伴隨人身風險:騷擾、濫訴、跨境壓力
- 對策:法務保險評估、公司/協會法人化時點(與文件 11 Phase 1 連動)、訴訟費預備金於財務規劃中列項、緊急下線與資料保全 runbook(文件 14)
