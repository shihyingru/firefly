# 04|AI 管線規格

> 螢火 Firefly|v0.2|2026-09-03|AGPL-3.0
> 原則:AI 是書記官。管線任何階段不得輸出立場推論。

## Stage 0:擷取與存證

- 輸入:公開貼文 URL(經正規化、去追蹤參數)
- 動作:抓取文字內容、發文帳號公開代號、時間戳;同步送 Wayback Machine 存檔
- 產出:PostSnapshot(含 archive_url)
- 失敗處理:非公開/已刪除 → 標記 unfetchable,回覆查詢者「無法取得內容」

## Stage 1:指紋偵測

三類訊號,各自獨立評分,不做加總裁決(證據並列,不下結論):

1. **排版指紋**:規則引擎。可設定的模式庫,初始規則含「N 行短句＋emoji＋尾行 hashtag」等已公開的農場排版公式;規則以 YAML 管理、開源、附出處
2. **網域指紋**:連結網域比對公開清單(見文件 09);記錄清單版本號,卡片引用時附版本
3. **時序指紋**:同叢集貼文的發布時間分布;計算同步性指標(如 N 帳號於 T 分鐘窗口內發布)

產出:SignalSet(每項含原始數據＋計算方式連結,皆可重跑)

## Stage 2:語意聚類

- 嵌入:多語 embedding 模型(候選:multilingual-e5 系列或同級,由實作時基準測試定案),向量入 pgvector
- 歸屬:新貼文向既有叢集做近鄰檢索,cosine 相似度 ≥ θ_join(初始 0.92,需實測校準)歸入;否則暫存為孤立點
- 成簇:孤立點達 K 篇(初始 K=3)且互相似度達標 → 成立新叢集
- 叢集生命週期:active → dormant(30 天無新增)→ archived;dormant 叢集復活時觸發卡片複審

## Stage 3:脈絡卡起草(確定性優先)

> v0.2 變更(2026-09-03,維護者決議):Stage 3 改為「確定性優先」。白名單七個欄位中,六個由程式直接計算,LLM 不參與。LLM 僅對 original_source 提出候選,且候選受封閉集合限制。理由:白名單欄位本質上皆可由 SignalSet 與快照庫算出;縮小 LLM 職責同時縮小 prompt injection 與幻覺的攻擊面(文件 14 T5)。

- 觸發:叢集成立或重大更新(同文帳號數跨閾值)
- **欄位白名單(硬約束)**與各欄位的產生者:

  | 欄位 | 內容 | 產生者 |
  |---|---|---|
  | earliest_seen | 最早出現時間＋出處連結 | 程式:叢集內 posted_at 最小值 |
  | original_source | 可追溯的最初來源(查無則明寫「未能追溯」) | 程式為主,LLM 可選(見下) |
  | account_count | 發布相同/近似內容的帳號數 | 程式:叢集內相異 author_handle 數 |
  | timing_chart | 同步發文時序圖(數據點陣列) | 程式:Stage 1 時序指紋 |
  | archive_links | 快照連結列表 | 程式:快照庫 archive_url |
  | domain_note | 網域比對結果＋清單版本 | 程式:Stage 1 網域指紋 |
  | sample_excerpt | 叢集內最早貼文的**逐字**節錄,長度上限由設定檔定義 | 程式截取,不經 LLM |

  sample_excerpt 的目的:讓仲裁者在佇列中知道卡片對應的說法內容。逐字引用不是立場推論。節錄不得改寫、不得摘要。

- **original_source 的產生規則**:
  1. 程式先建立「候選集合」:叢集內所有貼文 URL,加上貼文內文出現的所有外部連結
  2. 預設值:候選集合中 posted_at 最早的貼文 URL;若叢集內貼文皆無可辨識來源,填「未能追溯」
  3. LLM 步驟為**可選**(feature flag,預設關閉):LLM 只能從候選集合中挑選一個 URL,或回答「未能追溯」。LLM 不得產生集合外的 URL,不得輸出任何其他欄位
  4. LLM 啟用時,每叢集呼叫一次;prompt、模型版本、原始輸出全量寫入審計 log(公開)
- **後驗證(防幻覺)**:輸出經程式檢核——每個連結必須存在於快照庫或候選集合;數字必須與 SignalSet 相符;sample_excerpt 必須與快照 content_text 逐字一致;任一欄位驗證失敗 → 整卡退回重生,連續失敗進人工檢視佇列
- **禁止事項**:形容詞裁決(可疑/操弄/假)、意圖推測、立場描述。輸出 schema 以 JSON 驗證,超出白名單欄位即丟棄

## 成本模型

- 指紋:規則＋SQL,趨近零
- 嵌入:自架 small model,每千篇 < NT$1
- 起草:確定性計算趨近零;LLM 步驟關閉時無 API 成本。啟用時每叢集一次呼叫;以叢集數而非貼文數計費 → 46 萬貼文若壓成 500 叢集,起草總成本以百元計
- 查詢:全快取,零 AI 成本

## 品質迴圈

- 仲裁投票結果回饋:被評「沒幫助」比例高的卡片類型 → 檢討起草 prompt(修改需走公開 PR)
- 聚類錯誤回報管道:具名貢獻者可標記「此貼文不屬於此叢集」,達閾值觸發重聚類
