# 09|資料來源與引用政策

> 螢火 Firefly|v0.1|2026-07-20|AGPL-3.0

## 來源分級

| 級別 | 定義 | 使用方式 |
|---|---|---|
| A:具方法論的公開研究 | 附可驗證證據與方法的公開報告(如 Doublethink Lab 之無邊界集團研究) | 可直接納入 domain_signal;卡片引用附報告連結與清單版本 |
| B:平台官方公告 | Meta CIB 下架公告等 | 同 A |
| C:群眾提交 | 具名貢獻者提交的補充出處 | 僅作候選;經指紋驗證或雙重來源確認後升級 |
| D:自有偵測 | 本系統時序/排版/聚類訊號 | 以「觀測數據」呈現,附計算方式,不引為外部權威 |

不採用:匿名爆料、無方法論的立場媒體清單、任何政府機關提供之非公開名單(中立性紅線)。

## 引用規則

- 卡片內每一筆外部資料必附:來源名稱、連結、擷取日期、清單版本號
- 來源更新:A/B 級來源每週檢查;版本變動寫入 audit_log
- 來源撤回:上游撤回或修正 → 受影響卡片自動進複審佇列,期間標註「來源更新中」

## 申訴與移除

1. 受影響方(網域持有者、帳號本人)經公開表單提出,附身分佐證
2. 72 小時內初步回覆;複審由治理章程(文件 10)定義的複審小組執行
3. 成立:domain_signal 標記 removed_at(留痕不硬刪),相關卡片重生成
4. 不成立:回覆理由;申訴紀錄(去識別化)入公開統計
5. 全程不對申訴人身分公開;僅公開案件量與處理時效統計

## 蒐集邊界

- 僅擷取公開貼文;不繞過登入牆、不爬取私人內容
- 平台 API 可用者優先走 API;快照擷取遵守 robots 與速率禮儀
- 帳號層資料僅保存平台公開代號;不做跨平台身分串聯

## 本專案產出資料之授權

- 脈絡卡與訊號開放資料:CC BY 4.0(要求署名,允許商用——B2B 價值在額度與 SLA,非資料獨占)
- 程式碼:AGPL-3.0
- 引用本專案時之建議格式於 README 提供
