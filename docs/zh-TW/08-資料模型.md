# 08|資料模型

> 螢火 Firefly|v0.1|2026-07-20|AGPL-3.0
> 原則:最小蒐集;凡個資一律雜湊或不存;所有裁決可從資料重放。

## 實體

### post_snapshot(貼文快照)
| 欄位 | 型別 | 說明 |
|---|---|---|
| id | uuid PK | |
| source_url | text unique | 正規化後 URL |
| platform | enum | threads/facebook/other |
| author_handle | text | 公開帳號代號(平台公開資訊) |
| content_text | text | 擷取當下文字 |
| posted_at | timestamptz | 平台顯示時間 |
| fetched_at | timestamptz | |
| archive_url | text | Wayback 快照 |
| embedding | vector(768) | pgvector |
| cluster_id | uuid FK nullable | |

### cluster(說法叢集)
id、status(forming/active/dormant/archived)、created_at、post_count、account_count、signal_summary(jsonb:三類指紋原始數據)、current_card_id

### context_card(脈絡卡)
id、cluster_id FK、version、fields(jsonb,僅白名單欄位)、llm_model、prompt_ref(審計 log 指標)、validation_passed_at、state(draft/candidate/displayed/not_displayed)、quality_score(i_c)、vote_count

### contributor(貢獻者)
| 欄位 | 說明 |
|---|---|
| id | uuid PK |
| origin | enum:line_hash/device/threads_link |
| origin_key_hash | 單向雜湊(LINE userId 等原值不落地) |
| named_profile | nullable:自選暱稱(具名貢獻者) |
| stance_vector | float[](橋接引擎產出,僅供計分,不對外) |
| created_at / last_active_at | |

**明確不存**:IP(僅防濫用滾動窗口 24h 後即刪)、國籍、真實姓名、聯絡方式、任何平台原始識別碼。

### vote(投票)
contributor_id FK、card_id FK、helpful bool、created_at、weight(降權標記後 <1);(contributor_id, card_id) unique → 覆寫式冪等

### domain_signal(網域訊號)
domain、source_list(出處,如 DTL 報告)、list_version、evidence_url、added_at、removed_at nullable(申訴移除留痕不硬刪)

### audit_log(審計)
entity_type、entity_id、event、payload(jsonb)、created_at——卡片狀態變更、prompt/輸出、參數修改全入;**全表公開**

### finance_record(收支)
kind(donation/b2b/grant/expense)、amount、currency、counterparty_class(不記個別捐款人身分,僅類別)、note、occurred_at——供透明儀表板與開放資料

## 關聯圖(文字版)

```
post_snapshot >—— cluster ——< context_card ——< vote >—— contributor
domain_signal(獨立維度,經 signal_summary 引用)
audit_log / finance_record(事件流,append-only)
```

## 蒐集邊界三原則(硬約束,實作不得放寬)

1. **查詢聚合=內建可用**:使用者主動查詢產生的叢集層級統計(如「本週查詢量最高叢集」)為服務自然副產品,聚合後公開;不關聯至任何個人或裝置層級的長期輪廓
2. **被動閱讀追蹤=不做,含匿名版**:任何形式的「使用者讀了/滑過什麼」回報一律禁止。行為序列本身即指紋,匿名化不成立;客戶端不得內建瀏覽行為探針。若遠期出現人群層級統計的必要,唯一可接受路徑為裝置端本地聚合＋差分隱私上傳,且須經治理流程(文件 10)公開審議後才可實作
3. **識讀日記=純裝置端**:閱讀習慣鏡像功能之所有資料與運算(含統計與評語生成)留在本機,不上傳、不備份上雲、不要求帳號登入;評語生成優先採用裝置端本地模型。呈現遵循文件 02 語氣準則——攤開分布＋提問,不下「偏頗」裁決

## 留存政策

- post_snapshot:永久(證據性質);作者申訴經治理流程可遮蔽 content_text,保留雜湊與 archive 指標
- vote:永久(匿名);開放資料端 k-匿名化後發布
- 防濫用暫存(IP、速率窗口):24 小時滾動刪除
- 備份:每日加密異地;還原演練每季
