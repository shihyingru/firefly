# Contributing / 參與貢獻

## 繁中

歡迎參與。請先閱讀 [治理章程](docs/zh-TW/10-治理章程.md)——本專案的中立性承諾以公開流程保證,貢獻須符合其約束。

- **參數與規則變更**:一律走公開 PR,合併前公示 7 天(安全緊急修補除外)
- **硬約束**(文件 04/08/10/14):不接受繞道實作的 PR;遇困難請先開 issue 討論
- **回報偵測誤判**:請附可驗證證據(連結、時間、快照)
- 程式註解與文件更新請同步維護繁中/英文兩版

## English

Please read the [Governance Charter](docs/en/10-governance-charter.en.md) first — this project's neutrality commitments are guaranteed by public process, and contributions must respect them.

- **Parameter and rule changes**: always via public PR, with a 7-day notice before merge (security hotfixes excepted)
- **Hard constraints** (docs 04/08/10/14): PRs that work around them will not be accepted; open an issue to discuss instead
- **Reporting detection errors**: include verifiable evidence (links, timestamps, snapshots)
- Keep zh-TW and English versions of docs and comments in sync
